# G4.4 — First Governed Local AI Characterization Model

This document records the first governed characterization artifact for the
G4 Local AI experiment. It is not a production deployment, model registry,
systemd service, or scientific authority. The artifact was staged outside
the live AETHERIS release tree and exercised only with the validated
llama.cpp runtime.

## Bounded selection

| Candidate | Artifact / approximate size | Provenance and license | Decision |
| --- | ---: | --- | --- |
| Qwen2.5-3B-Instruct GGUF Q4_K_M | 2.10 GB | Qwen upstream file revision; `qwen-research` license | Selected |
| Gemma 3 4B IT GGUF Q4_K_M | 2.49 GB | ggml-org upstream GGUF; Gemma license | Not acquired |
| Phi-3.5 Mini Instruct GGUF Q4_K_M | approximately 2.4 GB | Microsoft upstream model; MIT license | Not acquired |

Qwen2.5-3B-Instruct was selected for the first characterization because it
provides a 3B technical-language baseline, multilingual capability relevant
to PT-BR probes, explicit upstream/file revisions, and a lower measured
artifact footprint than the 4B candidate. The choice is experimental and
does not preclude specialized Knowledge embedding/reranking models or a
future alternative backend.

## Controlled validation

The runtime was the G4.2 artifact built from llama.cpp commit
`6a1a922d269908a29cbd4b49c27e6a8e7fd10fae`. With `CUDA0` and 99 GPU layers,
the runtime reported 37/37 layers offloaded, a CUDA0 model buffer of
1,834.83 MiB, a 9 MiB KV buffer, and successful bounded generation.

Three functionality probes completed with non-empty output:

1. Portuguese technical explanation of citation provenance.
2. Citation-aware Knowledge synthesis without external retrieval.
3. RF interpretation preserving deterministic DSP and RAW IQ authority.

These probes establish functional loading and basic response behavior only.
They do not establish scientific correctness, production readiness, or a
benchmark classification. LLM output remains derived and interpretive;
Knowledge evidence, source documents, citations, RAW IQ, DSP measurements,
and scientific datasets remain authoritative.

The model was staged under `/tmp/aetheris-g4.4-governed-model` for this gate.
No model was installed into `/opt/aetheris`, no service was created, and no
live AETHERIS or NVIDIA state was changed.
