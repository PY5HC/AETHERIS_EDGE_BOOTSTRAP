## Authority finding

Governance registers `AETHERIS_AI` as the semantic authority for
`ai.model_semantics`, `ai.training`, and `ai.inference` in
`registry/repository-responsibilities.json`. The ecosystem repository
registry also lists `AETHERIS_AI` as the AI/ML domain repository.

The current GitHub organization inventory does not contain a repository
resolving as `PY5HC/AETHERIS_AI`, and no local checkout or alternate AI/ML
repository was found. This means the registered semantic authority has no
available implementation source authority for G4.6.

The Constitution requires inter-repository dependencies to use explicit,
versioned contracts, APIs, events, or artifacts, and prohibits transferring
domain semantics to runtime or deployment repositories. The responsibility
registry assigns local execution and resource materialization to
`AETHERIS_NODE_AGENT`, not AI semantic ownership.

Node Agent evidence at the audited source revision documents the external
scientific-runtime boundary in:

- `AETHERIS_NODE_AGENT/docs/adr/0001-node-agent-boundary.md`
- `AETHERIS_NODE_AGENT/docs/adr/0003-external-scientific-runtime-boundary.md`
- `AETHERIS_NODE_AGENT/docs/architecture/ARCHITECTURE_OVERVIEW.md`

Those documents explicitly keep model-specific execution logic outside the
Node Agent. Bootstrap owns deployment and validation contracts, not AI
application semantics. Implementing the Local AI service in either repository
would therefore create an ownership violation.

## G4.1 reconciliation

The following Bootstrap artifacts remain useful as provisional operational
contracts and evidence, but do not become ecosystem-normative AI semantics:

- `docs/G4.1-local-ai-contract.md`: backend-neutral contract proposal.
- `schemas/local-ai-model-record.schema.json`: operational model record shape.
- `schemas/local-ai-benchmark-record.schema.json`: benchmark evidence shape.
- `schemas/local-ai-runtime-capabilities.schema.json`: capability evidence shape.
- `templates/local-ai-model-record.json.template`: non-secret record template.
- `scripts/verify-local-ai-contract.sh`: static contract verifier.

They should be consumed by a future AETHERIS_AI implementation through an
explicit versioned boundary, or reconciled with a later Governance shared
contract. They must not be copied into Node Agent as domain logic.

## Forward progress available

The Knowledge repository documents a boundary at the Scientific Embedding Job:
Knowledge owns source preservation, canonical text, geometry, chunking and
embedding-job preparation; AI is intended to consume that job and produce
vectors/manifests. The RF repositories document acquisition, DSP, feature and
scientific-product boundaries and keep Local AI out of the realtime DSP path.

These facts support future G5/G6 contract and replay work, but do not provide
authority to implement a Local AI service without the registered AI owner.
