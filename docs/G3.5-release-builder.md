# G3.5 — Repository-only Node Agent release builder

`scripts/build-node-agent-release.sh` builds a disposable release from the
validated `PY5HC/AETHERIS_NODE_AGENT` commit
`4bb897e6b18644199ac89ad33be9292e7487c37b`. It requires an aarch64 Python
3.11-or-newer environment, verifies the hash-pinned `requirements.lock`,
installs the project console script into an isolated virtual environment, and
records source, package, interpreter, architecture, dependency, artifact,
health, and Governance provenance in the release manifest.

The caller must provide `NODE_AGENT_SOURCE_DIR`, `AETHERIS_RELEASE_ID`, and an
absolute `AETHERIS_RELEASE_OUTPUT`. Output under `/opt`, `/etc`, `/var`,
`/run`, or `/home` is rejected, so this builder cannot activate a live
release. It performs no account, systemd, Docker, GPU, NVIDIA, or host
filesystem authority operation. Activation, readiness probing, and rollback
remain separately governed gates.

The release uses the project-owned `bin/aetheris-node-agent` console script
and records the lock-file SHA-256. Governance provenance is
`PY5HC/AETHERIS_GOVERNANCE` at revision
`ff1318cd8f0a9720f66029e3985d1e5854044128`, version `1.3.0`, identity
contract `1.0.0`, with no edge-node profile established. `/opt/aetheris/current`
remains the G3.0/G3.1 v1 directory; no artifact is activated by this script.
